## 当前缺少

- Node.js >=24.11（环境现有 v20.19.2）。
- PostgreSQL 16 或 17；也未发现 Docker，不能走官方推荐的 Docker Compose 路径。
- 终端联网能力：github.com、registry.npmjs.org、nodejs.org 均报 Could not resolve host；环境标示的本地代理端口也无法连接。
- 如需采集后自动筛选和写摘要，需要可用的 OpenAI 兼容模型 API Key、接口地址、模型名，且账号有可用额度。当前 .env 的 LLM_API_KEY 留空。

## 已准备的 API 配置

.env 按官方模板生成随机管理员密码及签名密钥，权限为 600。仅供本地使用，不要提交或上传。

填写 LLM_API_KEY，并核对 LLM_BASE_URL、LLM_MODEL、LLM_EXTRA_JSON；默认值沿用仓库示例，未验证服务商实际可用性。

COLLECT_ENABLED=false、MODEL_CALLS_ENABLED=false，通知和 IndexNow 保持关闭。在明确接入真实信源和模型前保持这些设置。RSS 示例不需要单独购买采集 API；X、公众号、Jina、向量 API 是选填服务，不是本地启动的必需项。

## 网络及运行环境就绪后

按官方非 Docker 路径操作，使用独立的新目录；不要在 official-reference 下运行 npm ci，它只包含读取资料。

```bash
git clone https://github.com/KKKKhazix/AIHOT.git /workspace/AIHOT
cd /workspace/AIHOT
cp /workspace/AIHOT-setup/.env .env
npm ci
```

先启动 PostgreSQL，用一个可建库的本地账号创建 myhot 数据库，按真实账号更新 .env 的 DATABASE_URL。当前连接地址仅为待核对配置。

```bash
createdb myhot
node --env-file=.env scripts/migrate.ts
node --env-file=.env scripts/seed.ts
npm run build -w @aihot/web
```

分别在三个终端运行：

```bash
NODE_ENV=production node --env-file=.env apps/api/src/main.ts
NODE_ENV=production node --env-file=.env apps/worker/src/main.ts
cd /workspace/AIHOT/apps/web
NODE_ENV=production node --env-file=../../.env server.ts
```

成功后预期地址 http://localhost:3000，后台 /admin。管理员密码在 .env 的 ADMIN_PASSWORD 中。采集及模型关闭时，不会自动生成真实新闻内容。

验证：node scripts/smoke.ts --base http://localhost:3000。当前没有启动服务，因此未执行运行验证，也未安装依赖。
